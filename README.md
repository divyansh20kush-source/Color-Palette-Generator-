# HueCraft — Interactive Color Palette Generator 🎨
A lightweight, high-fidelity web utility tool built to help frontend developers and UI designers
seamlessly discover, curate, lock, and copy cohesive hex color schemes for their digital interfaces.

## ✨ Core Features
• 
• 
• 
• 
Dynamic Randomization Engine: Generate a brand-new five-color harmonious palette instantly
with a single button click.
Color Locking Matrix: Lock down individual color slots you love while re-randomizing the rest of
the layout.
Clipboard API Integration: Click any color hex string to instantly copy it to your clipboard with
immediate UI confirmation status updates.
Fully Responsive Architecture: Crafted with Tailwind CSS v3 utility classes to display beautifully
across mobile viewports, tablets, and wide desktop environments.
